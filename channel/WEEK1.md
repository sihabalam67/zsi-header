## When uploading each long video
1. Paste the title, description and tags from the `.upload.md` kit.
2. Upload the thumbnail `_a`, then use **Test & compare** to add `_b`.
3. Upload the `.en.srt` caption file (Subtitles -> Add language -> English -> Upload file -> With timing).
4. Settings: Education category, **Not made for kids**, **Altered or synthetic content: Yes**.
5. End screen: add "Best for viewer" video + Subscribe over the last 15 seconds (the outro leaves space).
6. Pin a comment asking a question (e.g. "What did a loaf of bread cost where you grew up?").
   Comments boost reach.

## Shorts
- Upload from the YouTube app or Studio. The `#shorts` tag is already in each title.
- In each Short, use **Related video** to link the matching long video, so Shorts viewers flow to it.
